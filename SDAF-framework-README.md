## Source of record

The files preserved in the Zenodo Version 1.0 record are the authoritative files for that release.

This GitHub repository is the living public workspace for:

- review and issue reporting;
- implementation guidance;
- templates and worked examples;
- standards and methodology mappings;
- pilot materials;
- interoperability work; and
- proposals for future versions.

Repository discussions, issues, pull requests and supporting materials do **not** silently amend the published v1.0 framework.

Any accepted change affecting the framework will be recorded in the project change log and, where appropriate, incorporated into a formally identified future release with its own version-specific DOI.
